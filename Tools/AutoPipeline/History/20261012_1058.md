### 3. `build_standalone_exe.bat` 오류 수정

**증상**: `build_all_exe.bat` 의 `[3/3] Standalone (ps2exe)` 단계에서
`"1"개의 인수가 있는 "Create"을(를) 호출하는 동안 예외가 발생했습니다. 위치 줄:2 문자:7`

**원인**: bat 상단의 PowerShell 런처는 파일 안에서 `:__PS_BEGIN__` 이 **처음 나오는 위치**부터 PS 코드로 실행한다.
5번째 줄 **주석**(`rem 1) ... 에서 :__PS_BEGIN__ 이후 ...`)에 같은 문자열이 있어 주석을 라벨로 오인 →
다음 줄 `rem  2) exe 실행 시 ...` 를 PS 로 파싱하다 `)` (줄 2, 문자 7) 에서 구문 오류.

**수정**: 주석의 라벨명에서 콜론 제거 + 경고 주석 추가

```bat
rem  1) auto_pipeline_standalone.bat 에서 __PS_BEGIN__ 라벨 이후 PS 섹션을 추출
rem     (주의: 이 파일의 rem 주석에 콜론+라벨명을 붙여 쓰면 아래 추출이 주석을 라벨로 오인함)
```

**확인**: `build_all_exe.bat standalone` → exit 0, `auto_pipeline_standalone.exe` (72KB) 생성.
`build_ps1_exe.bat`, `auto_pipeline_standalone.bat` 은 라벨 앞에 같은 문자열이 없어 문제 없음.
