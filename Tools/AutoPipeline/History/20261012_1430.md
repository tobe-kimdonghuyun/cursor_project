## 3. Q&A — git 동작 관련 질문

### 기존 full clone이 있는 PC에서 `--depth=1` fetch가 정상인가?

**결론: 정상 동작.**

- git fetch는 클라이언트가 HAVE 목록(로컬에 있는 커밋 해시)을 서버로 보내 협상
- 서버는 클라이언트가 이미 가진 커밋을 제외한 새 커밋만 전송
- `--depth=1`은 "1개 커밋만 받겠다"는 클라이언트 힌트이지만, 이미 부모 커밋이 있으면 결과적으로 shallow가 되지 않음
- 기존 full clone의 히스토리는 유지됨

### `--depth=1`이 pull 속도에 영향을 주나?

- 변경 없으면: ls-remote에서 hash 비교 후 fetch 건너뜀 → 훨씬 빠름
- 변경 있으면: 새 커밋 몇 개만 전송 → 기존과 비슷하거나 빠름
