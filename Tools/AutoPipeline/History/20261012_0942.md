  - 예: `-Block deploy` → 변경 없어도 [3]Deploy부터 실행

### 3. 실행 단계 결정 로직 (`invoke_target` 내)

```
do_from = 99 (아무것도 안 함)

source 변경 있음:
  git 방식  → do_from = 2 (Framework copy부터)
  package방식 → do_from = 3 (Deploy부터)

jar 업데이트됨:
  do_from = min(do_from, 3)  (Deploy부터)

-Block 지정:
  각 단계의 번호와 비교하여 do_from = min(do_from, 단계번호)

do_from == 99 → UNCHANGED 반환 (아무것도 실행 안 함)
do_from <= 2  → [2] Framework copy 실행 (git 방식만)
do_from <= 3  → [3] Deploy 실행
do_from <= 4  → [4] Publish 실행
[5] Chrome, [6] TestPro는 설정에 따라 항상
```
